# 🌿 Freya D Raja · Portfolio

A sage green, pixel-art, slightly unhinged portfolio for a cybersecurity student who finds holes for fun and patches them for money.

**Live site:** https://your-site.vercel.app

## What's inside

- **3D everything:** a draggable rotating cube with pixel-art faces, plus cards that tilt in 3D under your cursor
- **Pixel art drawn in code:** every sprite (shield, bug, cat, skull, lock, plant) is generated from a tiny character grid on a canvas, with no image files
- **Reactive background:** pixel leaves drift down and scatter away from your cursor, which leaves a pixel trail
- **Squashable bugs:** they crawl down the screen, and the counter keeps score
- **A cat with opinions:** poke it for a random security joke
- **Terminal and joke ticker:** fake terminal commands and cybersecurity one-liners
- **Light and dark mode:** a toggle in the nav, and it respects system preference
- **Hidden easter egg:** ↑ ↑ ↓ ↓ ← → ← → B A (keyboard only)
